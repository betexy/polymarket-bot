## Структура интеграции

```
Парсер → HTTP API → OrderManager
                        ↓
                  [Gamma API Client] (поиск markets)
                        ↓
                  [CLOB Client] (размещение ордеров)
                        ↓
                  Polymarket CLOB API
```

## Процесс работы

1. **Парсер отправляет ставку** на `POST /bets/`
2. **OrderManager получает ставку** и проверяет условия
3. **Поиск market** через Gamma API:
   - Поиск события по названиям команд
   - Получение markets для события
   - Фильтрация по типу market
4. **Извлечение token_id** из market данных
5. **Размещение ордера** через CLOB API:
   - Используем token_id
   - Рассчитываем цену из коэффициента
   - Размещаем ордер

## Настройка

### Требуется в .env файле:

```env
# CLOB API (обязательно для размещения ордеров)
POLYMARKET_PRIVATE_KEY=your_private_key_here

# Опционально (если уже есть API ключи)
POLYMARKET_API_KEY=your_api_key
POLYMARKET_API_SECRET=your_api_secret
POLYMARKET_API_PASSPHRASE=your_passphrase

# Настройки
POLYMARKET_CLOB_HOST=https://clob.polymarket.com
POLYMARKET_CHAIN_ID=137  # 137 для mainnet, 80001 для testnet
```

## Важно

⚠️ **Безопасность:**
- Используйте отдельный кошелек для бота
- НЕ храните приватный ключ в коде
- Используйте переменные окружения
- Ограничьте суммы на кошельке

⚠️ **Требования:**
- Для размещения ордеров нужен приватный ключ
- Кошелек должен иметь баланс USDC для торговли
- Рекомендуется сначала тестировать на testnet (chain_id=80001)
