# Информация о CLOB API для размещения ордеров

## Важное замечание

**Gamma API** (https://gamma-api.polymarket.com) - это **read-only API** для получения данных о markets, events, и другой информации. Он НЕ поддерживает размещение ордеров.

Для **размещения ордеров** на Polymarket требуется **CLOB API** (Central Limit Order Book API).

## CLOB API

Согласно документации Polymarket:
- CLOB API используется для размещения, отмены и управления ордерами
- Требует аутентификацию через Web3 кошелек
- Поддерживает размещение buy/sell ордеров
- Управление позициями и балансом

Документация: https://docs.polymarket.com/developers/central-limit-order-book/

## Текущая реализация

Текущая реализация бота использует **Gamma API** для:
- ✅ Поиска событий по названиям команд
- ✅ Получения информации о markets
- ✅ Фильтрации markets по типу (1X2, Тотал, Фора, Индивидуальный тотал)

**Размещение ордеров** пока не реализовано, так как требует интеграции с CLOB API.

## Следующие шаги для размещения ордеров

1. **Изучить CLOB API документацию:**
   - https://docs.polymarket.com/developers/central-limit-order-book/clob-introduction
   - Понять процесс аутентификации
   - Изучить endpoints для размещения ордеров

2. **Настроить Web3 кошелек:**
   - Создать кошелек для бота
   - Настроить приватные ключи
   - Пополнить баланс USDC

3. **Реализовать CLOB клиент:**
   - Создать модуль для работы с CLOB API
   - Реализовать подпись транзакций
   - Интегрировать с order_manager

4. **Протестировать:**
   - Тестировать на тестовой сети
   - Проверить размещение ордеров
   - Проверить отмену ордеров

## Альтернативные подходы

Если CLOB API сложен в интеграции, можно рассмотреть:
- Использование готовых SDK для Polymarket (если доступны)
- Использование Web3 библиотек для прямой работы с контрактами
- Интеграция через релейеры (relayers) если доступны
